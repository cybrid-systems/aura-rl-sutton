# Chapter 9 — On-policy Prediction with Approximation

Status: done (Fig 9.1, 9.2, 9.5, 9.8, 9.10)

| Driver | Book | What it does |
|---|---|---|
| `aggregation_mc_td.aura` | Example 9.1, Fig 9.1, Fig 9.2 (left) | gradient Monte Carlo and semi-gradient TD(0) on the 1000-state random walk, 10 groups of 100 states; prints each group's estimate next to v_π, the μ-weighted v_π (the gradient MC fixed point) and the on-policy distribution μ |
| `nstep_td_sweep.aura` | Fig 9.2 (right) | semi-gradient n-step TD, 20 groups: RMS error over the first 10 episodes for n = 1 … 64 and α = 0.1 … 1 |
| `coarse_coding.aura` | Example 9.3, Fig 9.8 | 50 interval features of width 0.2 / 0.4 / 1.0 learning a square wave from 10 … 10 240 samples |
| `tile_coding.aura` | Fig 9.10 | gradient MC with one tiling (state aggregation, tiles 200 wide) vs several offset tilings |
| `poly_fourier.aura` | Fig 9.5 | gradient MC with polynomial and Fourier bases of order 5 / 10 / 20 (α = 10⁻⁴ / 5·10⁻⁵ as in the book); RMS error at 10 %, 50 % and 100 % of the episodes (default 1 000 episodes, 1 run; the book uses 5 000 × 30) |

Library code: `lib/envs/walk1000.aura` (the walk), `lib/algos/approx.aura` (tile coder over integer states, gradient MC,
semi-gradient n-step TD, coarse coding), `lib/algos/basis.aura` (polynomial / Fourier features), `lib/oracle/walk1000-exact.aura` (exact v_π, generated by
`tests/oracle/walk1000_exact.py`). Tests: `tests/test_ch09_approx.aura`, `tests/test_ch09_basis.aura`.

The walk's dynamics do not depend on the value estimate, so each episode is generated first and the updates are
applied afterwards in time order; that gives the same weights as updating online.

Fig 9.5 at the defaults (1 run, 1 000 episodes): after 1 000 episodes the RMS error is 0.28 / 0.30 / 0.31 for
polynomial order 5 / 10 / 20 and 0.23 / 0.24 / 0.24 for Fourier. Fourier is ahead, as in the book; the orders only
separate over the book's 5 000 episodes.

Reference implementation (Python, for cross-checking numbers only): `chapter09/random_walk.py, square_wave.py` in
[ShangtongZhang/reinforcement-learning-an-introduction](https://github.com/ShangtongZhang/reinforcement-learning-an-introduction).
Code here is written from the book's pseudocode; no code or prose is copied.

Run: `scripts/run_chapter.sh 9`
