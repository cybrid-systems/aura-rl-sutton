# Chapter 5 — Monte Carlo Methods

Status: done for Fig 5.1–5.4 and Sec 5.4, at Soft-practical run sizes.

| Driver | Book | What it does |
|---|---|---|
| `mc_prediction.aura` | Example 5.1, Fig 5.1 | first-visit and every-visit MC prediction of v_π for "stick on 20/21"; prints both value grids and the RMS error against exact values |
| `mc_control.aura` | Fig 5.2, Sec 5.4 | Monte Carlo ES (exploring starts) and on-policy first-visit MC control with an ε-soft policy; prints π_* grids, agreement with the exact optimal policy, mean return of the learned greedy policy |
| `off_policy.aura` | Fig 5.3, Fig 5.4 | ordinary vs weighted importance sampling for the state (13, usable ace, dealer 2); ordinary IS on the infinite-variance one-state MDP |

Code: `lib/algos/mc.aura`, env `lib/envs/blackjack.aura`, exact oracle `lib/oracle/blackjack-exact.aura`
(generated by `tests/oracle/blackjack_exact.py`, a small exact DP over the same rules).

Rules: infinite deck, dealer sticks on 17 or more, no natural bonus. The exact value of
(13, usable ace, dealer 2) under "stick on 20/21" is -0.2772 with these rules (book: -0.27726).
In blackjack a state never repeats within an episode, so first-visit and every-visit MC give
identical tables; the driver and tests check that.

Run sizes (defaults): 10 000 episodes for Fig 5.1 (book: 10 000 and 500 000), 50 000 for
MC ES and ε-soft (book: 500 000), 20 runs × 1 000 episodes for Fig 5.3 (book: 100 × 10 000).
The Soft interpreter takes about 1.5 ms per episode. Knobs: `RL_EPISODES`, `RL_RUNS`,
`RL_EPS`, `RL_EVAL`, `RL_IV_RUNS`, `RL_IV_EPISODES`, `RL_SEED` (see each file header).

Results at the defaults (Aura `2f815c188`, seed 2026) are in the top-level README.
Tests: `tests/test_ch05_mc.aura`.

Reference implementation (Python, for cross-checking numbers only): `chapter05/blackjack.py, infinite_variance.py` in
[ShangtongZhang/reinforcement-learning-an-introduction](https://github.com/ShangtongZhang/reinforcement-learning-an-introduction).
Code here is written from the book's pseudocode; no code or prose is copied.

Run: `scripts/run_chapter.sh 5`
